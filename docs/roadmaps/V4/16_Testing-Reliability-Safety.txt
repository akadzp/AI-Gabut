V4 — TESTING, RELIABILITY & SAFETY

execution menjadi panjang, autonomous, dan menghasilkan external effect.

- planning/execution contracts
- authorization / approval
- cross-user isolation
- change/diff integrity
- verification
- repair loop limits
- cancellation
- timeout
- background execution
- restart / resume
- realtime / reconnect
- connector failures
- CI feedback
- end-to-end autonomous workflow

DoD: Happy path dan failure path utama tervalidasi, autonomous loop
mempunyai batas yang dapat ditegakkan, dan V2/V3 foundation tetap lulus.
