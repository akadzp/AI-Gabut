Security notes:
- Continuity receipts use Ed25519 signatures and trusted public keys. Receipt signature validity and current checkpoint binding are reported separately.
- Completed recovery-journal provider conformance reports are retained automatically. Retained payloads are digest-checked and expire into tombstones that preserve the original payload digest and expiration metadata.
- Retention evidence is bounded at 500 active / 2000 total records per owner; pruning is bounded at 100 records per operation and fails closed if audit detects tampering.
- Cross-domain audit detects same provider instances and shared stable backend/endpoint identity fingerprints. Missing or opaque provider identities degrade the result; duplicate identities make it unhealthy. This audit does not cryptographically prove independent administration of backing infrastructure.
- HTTP external anchor providers expose only a non-secret `providerIdentity` value for audit purposes; bearer tokens are never included in audit output.
