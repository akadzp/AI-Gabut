IMPORTANT SCOPE NOTE
--------------------
V3 is the application and integration foundation.

V3 is not defined as the complete autonomous AI development product.
GitHub is one provider implementation inside the integration layer.

V3 therefore supplies the primitives required by V4:
- Agentic application lifecycle
- user/session isolation
- memory/context
- connection/provider relationship
- GitHub capability
- workspace context
- activity/realtime
- approval/security
- persistence/recovery
- frontend/backend boundary

V4 owns the higher-level development work workflow:
- understand repository
- plan work
- modify workspace
- verify
- repair/replan
- commit/push/PR
- consume CI/external feedback
- continue bounded autonomous work
- report external outcome
