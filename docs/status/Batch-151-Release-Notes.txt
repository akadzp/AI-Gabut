Batch 151 — Audit-Attestation External Checkpointing, Provider-Baseline Lifecycle Continuity, and Retention-Review Decision Replay Protection

Implemented
-----------
- Added separate external snapshot checkpoint domains for signed cross-domain audit attestations, provider-baseline lifecycle history, and retention-review approval decisions. Each supports status, explicit legacy enrollment, CAS-based reconciliation, marker repair, and integrity audit.
- Audit-attestation checkpoint snapshots bind retained attestation IDs, record digests, signed payload digests, issuance timestamps, and key IDs. Attestation verification distinguishes historical validity from current-decision usability; current usability requires an aligned external checkpoint when configured.
- Provider-baseline lifecycle checkpointing reconstructs completed per-domain transition history from baseline challenges, validates challenge/report digests, conformance report linkage, revision order, expected previous baseline digest, result digest, and current-baseline pointer.
- Provider-baseline checkpoint advancement requires exactly one appended transition and a prior-snapshot digest match after removing the single new terminal transition. Same-count rewrites, invalid history, and multi-step jumps are rejected.
- Retention-review decisions use deterministic replay keys and deterministic approval IDs. A durable replay guard is reserved before approval creation, interrupted finalization can resume idempotently, concurrent requests create at most one approval, and audits detect duplicate decisions or replay-guard tampering.
- Retention review remains non-destructive. New decisions are blocked while an existing decision is not externally checkpointed; the first decision is retained locally as pending until explicit enrollment establishes an external baseline.
- Added authenticated application APIs and HTTP routes for all three checkpoint domains. Added provider instance and endpoint independence checks. Fixed generic external-checkpoint audit status precedence for unhealthy and pending results.
