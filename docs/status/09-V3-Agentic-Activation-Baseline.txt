V3 AGENTIC ACTIVATION — BASELINE / HISTORICAL HANDOVER

The original V3 activation baseline is preserved here as a historical
starting point. It must not be read as the current implementation status.

------------------------------------

- restart/resume user workflow
- V3 production readiness

CURRENT HANDOVER
----------------
The gaps above were the activation baseline, not the current state.
Batches 01–04 have since delivered application authentication/session
ownership, Agent execution lifecycle, approval/resume and cancellation
backend flows, and the Memory & Context foundation.

Use docs/status/00_Current-Status.txt as the authoritative current-status
handover document. Use source code and the current test suite as the
implementation authority when documentation conflicts with code.

HANDOVER RULE
-------------
Roadmap = target.
Status = current condition.
Source code = implementation authority.
Tests = validation evidence.
Do not mark a feature completed merely because a contract or placeholder
UI exists.
