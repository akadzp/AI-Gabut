TUJUAN
======

V3 mengaktifkan Agentic sebagai application nyata di atas V2 dan
membangun integration foundation yang reusable.

Agentic harus dapat:
1. menerima user secara aman;
2. mempunyai session/chat terpisah;
3. menjaga context dan memory;
4. menghubungkan provider eksternal;
5. menggunakan GitHub sebagai provider pertama;
6. mempunyai workspace yang mengikuti resource yang dipilih;
7. menerima pekerjaan nyata;
8. memahami → merencanakan → bertindak → mengamati → mengevaluasi →
   memperbaiki/replan → menyelesaikan → melaporkan;
9. meminta approval bila diperlukan;
10. menyimpan execution state;
11. resume setelah restart;
12. mempunyai frontend dan backend yang dapat satu server atau terpisah;
13. menjaga isolasi antar-user;
14. menyediakan observability, audit, recovery, dan operations.
