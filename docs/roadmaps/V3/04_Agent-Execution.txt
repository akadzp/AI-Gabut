V3 — AGENT EXECUTION ACTIVATION

TUJUAN
Menghubungkan application Agentic dengan public Agent Engine boundary tanpa membuat engine kedua di apps/agentic.

SCOPE BATCH 02
- task understanding
- goal/context assembly
- planning
- capability/tool selection
- governed execution
- observable activity
- execution ownership
- application-visible status
- approval bridge
- cancellation
- checkpoint/resume integration
- execution inspection

BOUNDARY
Agentic owns user/session/execution/task/activity ownership and API lifecycle.
AI-Gabut Agent Engine owns generic reasoning, planning, tool execution, locking, timeout, checkpointing, and resume mechanics.
Core security governance remains authoritative for authorization and approval.

STATUS CONTRACT
completed | stopped | max_turns | failed | cancelled | waiting_approval

DoD
A real work command from an authenticated Agentic session creates a user-owned execution, emits observable activity, preserves bounded outcomes, can require approval, can resume the same checkpoint after approval, and can be cancelled cooperatively without exposing another user's execution.
