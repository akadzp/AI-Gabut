AUDIT SUMMARY:
- Reliability checkpoints already persist execution state as JSON.
- Workspace manager directly persists workspace files.
- Sessions, memory, approvals, locks, metrics, and several caches remain
  process-local.
- `core/storage/` is currently structural and has no canonical storage API.
- `data/` and `runtime/` provide reserved state locations but do not yet
  have a unified lifecycle/ownership contract.
- Snapshot, transaction, idempotency, indexing, object/blob, and cache
  contracts are not yet implemented.

IMPORTANT:
Roadmap 04 must introduce storage contracts without taking ownership
away from Workspace, Agent Engine reliability, Security, Tasks, or
Connectors where those subsystems already own their domain behavior.
