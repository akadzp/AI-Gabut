Agentic AI V4 — Batch 175 Release Notes
======================================

Scope
-----
- Added Ed25519 lifecycle attestations for CAS-finalization receipt revocation and replacement events.
- Bound each lifecycle attestation to the immutable event body, event sequence, previous-event digest, challenge binding, receipt binding, recovery-intent binding, signing-key fingerprint, and key-lifecycle cutoff.
- Preserved historical signature verification while distinguishing current usability after key rotation, stale timestamps, missing lifecycle proof, and external checkpoint requirements.
- Added durable recovery intents before receipt lifecycle events are appended, with bounded CAS updates and explicit completed/local-only/history-unproven/checkpoint-pending states.
- Added recovery for persisted revocation/replacement events whose local recovery intent was not finalized, including intent-bound recovery of a missing external checkpoint marker when the anchor postcondition proves the source.
- Added a cross-domain recovery-intent integrity audit that composes the intent-ledger snapshot, remediation CAS/finalization audit, replay-incident recovery-intent audit, and receipt-lifecycle recovery-intent audit.
- Added authenticated APIs for lifecycle attestation verification/audit, lifecycle recovery-intent audit/recovery, and cross-domain recovery-intent ledger integrity audit.
- Kept evidence append-only. No receipt deletion, evidence deletion, or automatic compaction is performed.

Operational limitations
-----------------------
- If no lifecycle-attestation signer is configured and attestation is optional, lifecycle events are retained with attestation status unavailable; if attestation is required, initialization and event creation fail closed.
- A valid historical signature is not automatically current after key rotation or revocation.
- External anchor commits and local storage do not form one distributed atomic transaction. Recovery intents preserve the evidence needed to resume or block safely.
- A recovered marker may remain history-unproven; the system does not infer pre-enrollment trust.
- Recovery refuses to replay a missing lifecycle event automatically. It marks the intent recovery-required for explicit investigation.
