Batch 12 — Persistence, Recovery & Continuity
- Agentic state remains backed by the existing state storage abstraction.

- Optimistic version checks are used for credential/execution transitions.

Batch 13 — Deployment & Operations
- Deployment configuration distinguishes same-origin and split topology.
- Split topology requires explicit allowed origins.
- API base URL and request/body settings are validated.
- Security response headers are provided by the deployment contract.

- Realtime tests are included in the Agentic test layer.
