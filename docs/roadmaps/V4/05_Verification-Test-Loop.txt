- failure extraction from test output

- explicit local execution directory boundary
- timeout and output resource limits
- retained verification evidence linked to Work.evidenceIds

BOUNDARY
--------
V4 owns verification evidence and Work-level outcome semantics.
The verifier does not become a second Agent Engine and does not execute
through a shell. A local cwd must be explicit; V3 remote Workspace context
is not silently treated as a filesystem checkout.
